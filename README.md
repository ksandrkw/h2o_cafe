# H2O cafe — сайт + Telegram адмін-бот

## Що реалізовано
- адаптивний сайт H2O cafe;
- онлайн-форма замовлення;
- 18,9 л як формат доставки;
- вибір виду води та кількості бутлів;
- дата і час отримання;
- спосіб розрахунку;
- передавання замовлень у Telegram;
- Telegram-бот з авторизацією за секретним паролем;
- авторизація зберігається в SQLite;
- `/start` — запросити пароль;
- `/logout` — відкликати доступ;
- після авторизації нові замовлення приходять у цей чат;
- 5 неправильних спроб підряд → пауза 60 секунд;
- webhook захищений Telegram `secret_token`.

## Важливо
Ця версія розрахована на Node.js сервер з постійним диском, бо авторизація бота зберігається в `data/h2o.sqlite`.


## Налаштування

6. Власник відкриває бота і надсилає `/start`.
7. Бот пише `Введіть пароль:`.
8. Після правильного пароля chat ID зберігається в SQLite.
9. Після цього кожне замовлення із сайту надсилається авторизованому чату.

## Telegram-пароль
Бот не повідомляє довжину пароля. Для захисту від перебору після 5 неправильних спроб робиться пауза на 60 секунд.
